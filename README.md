# 🌤️ Aplicativo Meteorológico

Este é um aplicativo meteorológico simples que atualmente obtém a **latitude** e **longitude** (configuradas para Belo Horizonte) e exibe os dados do clima na tela.

## Funcionalidades Atuais
- Obtém a latitude e longitude configuradas manualmente.
- Faz requisições a uma API de clima.
- Exibe os dados meteorológicos na tela.
